# Candidate forms — not yet katas

**A kata is only added after you have run it twice informally.** Otherwise the library
fills with forms that sounded good and nobody repeats, and the rep counts stop meaning
anything.

These are candidates. Run one on a normal study day first. If it survives twice, promote
it to its own file.

- **diagnose-without-running** — take a failing spec, predict the cause and the line from
  the failure text alone, then check. Records the prediction and whether it held.
- **draw-the-data-flow** — trace one request end to end from memory, then verify.
- **three-registers** — write one paragraph as self / teammate / newcomer, audit against
  `/pro-voice`. Tests the axes rather than the invariants.
- **read-the-gem** — read the source of a dependency you use daily and cannot explain.
